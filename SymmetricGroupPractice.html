Composition strategy

Why reversal works

If a cycle sends a → b → c → a, its inverse must undo those arrows: a → c → b → a.

(a b c)−1 = (a c b)

Cycle-to-transposition rule

For a k-cycle, hold the first symbol fixed and work backward:

(a₁ a₂ … ak) = (a₁ ak) ··· (a₁ a₃)(a₁ a₂)
  • A k-cycle uses k − 1 transpositions.
  • An even number of transpositions means the permutation is in An.
  • The decomposition is not unique, but parity is.
