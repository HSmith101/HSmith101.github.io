# Hanson Smith website refresh

This folder is a drop-in replacement for the four public HTML pages reviewed on August 27, 2026.

## Install

1. Back up the current site files.
2. Upload these files to the same directory as the existing site:
   - `index.html`
   - `research.html`
   - `teaching.html`
   - `3MinuteThesis.html`
   - `styles.css`
   - `site.js`
   - `home-hero.webp`
   - `research-panorama.webp`
   - `teaching-photo.webp`
3. Keep the existing `CV.pdf`, `favicon.ico`, `ClimbingaThing.jpg`, and linked presentation PDFs in place.
4. Replace the `TBA` office-hour values in `teaching.html` when they are known.

No framework, package manager, or build step is required. Filename capitalization matters on GitHub Pages.

## What changed

- Responsive, wrapping navigation with an active-page indicator
- Modern system typography, spacing, colors, cards, and readable line lengths
- Semantic headings, landmarks, skip links, visible keyboard focus, and descriptive image text
- Unique page titles and descriptions
- Keyboard-accessible publication abstract buttons with unique IDs
- Responsive 16:9 video embed
- Clickable email address
- Optimized WebP photographs with explicit dimensions
- Corrected “Mathematican” and “colleages” typos

The original JPG images were about 2.4 MB combined. The replacement WebP files are about 300 KB combined.
