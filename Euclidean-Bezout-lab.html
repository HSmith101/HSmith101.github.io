The central theorem

For integers a, b (not both zero), there exist integers x, y such that
ax + by = gcd(a,b).

This is Bézout’s identity. The Euclidean algorithm finds the gcd; the extended Euclidean algorithm finds a pair of coefficients x, y. The pair is not usually unique.

Think about the meaning: gcd(a,b) is the smallest positive integer expressible as ax + by with integer x and y. In fact, every integer combination ax + by is divisible by gcd(a,b).

From Bézout to bigger ideas

1. Divisibility

If d = gcd(a,b), then d divides every ax + by. The extended algorithm exhibits a combination equal to d.

2. Integer solutions

The equation ax + by = c has integer solutions exactly when gcd(a,b) divides c.

3. Modular inverses

If gcd(a,m) = 1 and ax + my = 1, then x is a multiplicative inverse of a modulo m.
